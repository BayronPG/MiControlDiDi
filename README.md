# MiControlDiDi

Aplicación Android para gestionar viajes, gastos y ganancias de un conductor de moto.

## Estado
El proyecto está en fase de análisis y preparación técnica.

## Documentos importantes
- `docs/SRS_MiControlDiDi_v1.docx`: requisitos del producto.
- `AGENTS.md`: reglas obligatorias para ClawCode.
- `TASKS.md`: backlog de trabajo.
- `PROJECT_STATUS.md`: estado actual.
- `PROMPT_INICIAL_CLAWCODE.md`: primera instrucción para el agente.

## Cómo comenzar
1. Descomprime esta carpeta.
2. Ábrela como espacio de trabajo en ClawCode.
3. Inicia Git en la raíz si todavía no existe.
4. Ejecuta únicamente el contenido de `PROMPT_INICIAL_CLAWCODE.md`.
5. Revisa el plan antes de permitir que el agente programe.

La carpeta `app` está vacía intencionadamente. ClawCode o Android Studio deben crear allí el proyecto Android después del análisis inicial.
